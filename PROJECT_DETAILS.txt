================================================================================
                                  OVERVIEW
================================================================================

Context-Aware AI Eraser is an intelligent privacy protection tool that 
automatically detects and anonymizes sensitive information in images using 
AI-powered object detection.

The system detects:
  - Faces
  - License Plates  
  - ID Cards/Badges

And applies context-aware anonymization based on Public or Private mode.

================================================================================
                              HOW THE CODE WORKS
================================================================================

1. IMAGE UPLOAD (frontend/script.js → api/routes.py)
   - User uploads image via drag-and-drop or file picker
   - Frontend sends POST request to /upload endpoint
   - Backend saves file to samples/input/

2. PIPELINE PROCESSING (core/pipeline.py)
   - Image is loaded via OpenCV
   - **OPTIMIZATION**: Resized to max 1280px for faster processing
   - Three detectors run in sequence:
     a) Face Detector (YOLOv8)
     b) License Plate Detector (YOLOv8)
     c) ID Card Detector (YOLOv8)
   - Each detector returns bounding boxes with confidence scores

3. ANONYMIZATION (core/eraser.py)
   - Based on context (Public/Private), different rules apply:
   
   PUBLIC MODE:
     - License Plates: BLUR
     - ID Cards: BLUR
     - Faces: NOT MODIFIED (preserved for usability)
   
   PRIVATE MODE:
     - License Plates: ERASE (inpainting)
     - ID Cards: ERASE (inpainting)
     - Faces: BLUR
   
   - **OPTIMIZATION**: Inpainting uses ROI-based processing (only the 
     detection region is processed, not the full image)

4. OUTPUT
   - Processed image saved to samples/output/
   - Path returned to frontend
   - User can compare original vs processed with slider
   - Download button available

================================================================================
                              RUNNING THE PROJECT
================================================================================

LOCAL DEVELOPMENT:
  1. Install dependencies:
     $ pip install -r requirements.txt
  
  2. Run the server:
     $ python3 -m api.app
  
  3. Open browser:
     http://127.0.0.1:5001
     
     NOTE: Port 5001 is used because macOS AirPlay uses port 5000.

CLOUD DEPLOYMENT (Render):
  - Procfile configured: gunicorn api.app:app
  - Push to GitHub → Render auto-deploys

================================================================================
                              OPTIMIZATIONS MADE
================================================================================

1. IMAGE RESIZING
   - Large images (4K+) are resized to max 1280px before detection
   - Maintains aspect ratio
   - Reduces inference time from 10+ seconds to <1 second

2. LOCALIZED INPAINTING
   - Instead of processing entire image for erase operations
   - Only the region of interest (ROI) + padding is processed
   - ~50x faster for typical use cases

3. STRICT JSON RESPONSES
   - Backend always returns JSON (never HTML error pages)
   - Frontend handles errors gracefully
